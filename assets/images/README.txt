DAFTAR GAMBAR POSTER YANG PERLU DICARI
=====================================
Letakkan semua gambar di folder: assets/images/
Format yang disarankan: .jpg (Potrait / tegak, ukuran sekitar 500 x 750 pixel)

Nama file yang harus sama persis dengan data di lib/data.dart:

1.  petualangan_langit.jpg      -> Petualangan Langit (Action)
2.  kota_tanpa_cahaya.jpg       -> Kota Tanpa Cahaya (Drama)
3.  tertawa_sampai_sore.jpg     -> Tertawa Sampai Sore (Comedy)
4.  rumah_tua.jpg               -> Rumah Tua di Ujung Jalan (Horror)
5.  negeri_awan.jpg             -> Negeri Awan (Animation)
6.  balapan_terakhir.jpg        -> Balapan Terakhir (Action)
7.  cinta_di_stasiun.jpg        -> Cinta di Stasiun Tua (Drama)
8.  komedi_anak_kos.jpg         -> Komedi Anak Kos (Comedy)
9.  bisikan_di_loteng.jpg       -> Bisikan di Loteng (Horror)
10. robot_kecil.jpg             -> Robot Kecil Pemberani (Animation)

Catatan:
- Selama gambar belum dimasukkan, aplikasi tetap berjalan normal.
  Poster akan diganti dengan ikon film sebagai placeholder.
- Jika ingin memakai format .png, ubah juga nama file pada bagian 'poster'
  di lib/data.dart.
